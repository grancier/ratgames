# ratgames — browser shell

Runs the ratgames titles in the browser via WebAssembly. The games and demos
(rules, screens, rendering) are the **same Rust the native binaries run**; this
directory is only the small shells the browser owns — the canvas, the keyboard,
and *when* to draw — plus the build/serve tooling. It lives outside the Cargo
workspace and depends on it only through the built `.wasm`.

Two things are served:

- **`/`** — mazegame (`mazegame-web` over `mazegame-app`).
- **`/examples/`** — the toolkit's demo gallery (`demos-web` over the `demos`
  crate): a generated menu, and a playable page per demo at
  `/examples/<slug>/`.

## How it fits together

```
mazegame-web (cdylib)        #[wasm_bindgen] shell: start(canvas, seed)
  └─ mazegame-app (lib)      the shared game construction (Ctx + ScreenStack)
       └─ ratgames [wasm]    WasmHost blits the Surface to <canvas>; embedded font

demos-web (cdylib)           #[wasm_bindgen] shell: start(name, canvas)
  └─ demos (lib)             every example's screens + construction, shared
       └─ ratgames [wasm]      verbatim with ratgames/examples/*.rs
```

Both shells build with the crate-bundled DejaVu Sans Mono
(`FontSource::Embedded`), since the browser has no system fonts.

The gallery's pages are generated by `build.mjs` from the one manifest in
`gallery.mjs`; `src/example.ts` is the shared player. A demo that animates
(`demo.animated`) runs a continuous `requestAnimationFrame` loop; an input-only
demo renders **synchronously in the keydown handler** — nothing re-renders
between presses, and there is no rAF defer on input.

## Prerequisites

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.126 --locked   # match the crate
# wasm-opt (Binaryen) is only needed for --release
npm install
```

## Build & run

```sh
npm run build          # debug bundle -> dist/
npm run build:release  # wasm-opt -O3 + minified JS
npm run serve          # http://localhost:8080  (application/wasm MIME, CSP)
npm run dev            # build + serve
npm run typecheck      # tsc --noEmit
```

`dist/` and `generated/` are build output (git-ignored). `serve.mjs` is a local
preview server (it also 301s extensionless routes to their trailing-slash form
and serves directory `index.html`s); for production, serve the immutable,
content-hashed assets from a CDN (or Node/Fastify) with
`Content-Type: application/wasm`, `Cache-Control: immutable` on hashed files,
`no-cache` on `index.html`, and the CSP `serve.mjs` sets.

## Controls

mazegame: arrow keys move one tile per press; `R` restarts the level, `N`
re-deals it, Enter advances a cleared level, Esc quits. Each gallery page shows
its own key help; Esc always returns to the menu.
